# A股股票分析程序设计文档

## 设计概述
本程序是一个专为A股设计的股票分析工具，通过模块化架构实现数据获取、技术指标计算和趋势分析功能，最终以控制台文本形式输出分析结果。

## 设计目标
1. 支持多种A股代码输入格式（6位数字、完整代码、中文名称）
2. 获取近6个月日线数据进行技术分析
3. 计算MA、RSI、MACD、布林带等技术指标
4. 基于多个指标给出综合趋势判断（看涨/看跌/震荡）
5. 提供用户友好的控制台输出
6. 包含健壮的错误处理机制

## 架构设计
采用模块化设计，分为四个主要模块：

### 1. 数据获取模块 (data_fetcher.py)
**职责**：
- 智能解析股票代码输入
- 下载股票历史数据
- 处理数据格式化和清洗

**核心功能**：
- 代码解析器：支持 `000001`、`000001.SZ`、`600000.SS`、`平安银行` 等多种格式
- 交易所判断：深交所(.SZ)或上交所(.SS)
- 数据下载：使用tushare获取近6个月日线数据（开盘、收盘、最高、最低、成交量）
- 错误处理：无效代码、网络错误、数据缺失

### 2. 技术指标模块 (technical_indicators.py)
**职责**：
- 计算各类技术指标
- 处理指标数据格式

**计算的指标**：
1. **移动平均线 (MA)**
   - MA5：5日简单移动平均线
   - MA20：20日简单移动平均线
   - MA60：60日简单移动平均线

2. **相对强弱指数 (RSI)**
   - 14日RSI，计算涨跌幅的平均值

3. **移动平均收敛散度 (MACD)**
   - 快线(12日EMA)、慢线(26日EMA)
   - DIF = 快线 - 慢线
   - DEA = DIF的9日EMA
   - MACD柱状图 = (DIF - DEA) × 2

4. **布林带 (Bollinger Bands)**
   - 中轨：20日移动平均线
   - 上轨：中轨 + 2倍标准差
   - 下轨：中轨 - 2倍标准差

**实现方式**：
- 使用pandas和numpy进行指标计算
- 避免外部依赖（如ta-lib）以确保兼容性

### 3. 趋势分析模块 (trend_analyzer.py)
**职责**：
- 分析技术指标信号
- 给出综合趋势判断
- 提供判断理由

**判断逻辑**：
1. **价格与均线关系**
   - 看涨信号：价格 > MA5 > MA20 > MA60
   - 看跌信号：价格 < MA5 < MA20 < MA60

2. **RSI信号**
   - 超买：RSI > 70（短期可能回调）
   - 超卖：RSI < 30（短期可能反弹）
   - 中性：RSI在50附近

3. **MACD信号**
   - 金叉：DIF上穿DEA（看涨）
   - 死叉：DIF下穿DEA（看跌）

4. **布林带信号**
   - 上轨突破：价格 > 上轨（可能超买）
   - 下轨突破：价格 < 下轨（可能超卖）
   - 通道内运行：趋势延续

**趋势判断规则**：
- **看涨**：至少3个指标支持看涨，且无强烈看跌信号
- **看跌**：至少3个指标支持看跌，且无强烈看涨信号
- **震荡**：指标矛盾或无明显趋势信号

### 4. 主程序模块 (main.py)
**职责**：
- 协调各模块工作流程
- 处理用户交互
- 格式化输出结果

**程序流程**：
```
1. 获取用户输入（股票代码）
2. 调用数据获取模块下载数据
3. 调用技术指标模块计算指标
4. 调用趋势分析模块判断趋势
5. 格式化并输出结果
```

## 数据流设计
```
用户输入 → 代码解析 → 数据下载 → 指标计算 → 趋势分析 → 结果输出
     ↓          ↓          ↓          ↓          ↓          ↓
 验证输入  判断交易所  获取6个月  计算MA/RSI  分析信号  格式化显示
             补充后缀  日线数据   MACD/BB    综合判断  风险提示
```

## 错误处理策略
1. **网络错误**
   - 重试机制：最多重试3次，每次间隔2秒
   - 降级处理：网络不可用时提供本地缓存数据（如果可用）

2. **无效股票代码**
   - 验证输入格式
   - 提供友好错误提示和示例
   - 建议正确的代码格式

3. **数据不足**
   - 检查数据天数是否满足指标计算要求
   - 不足时跳过需要更多数据的指标计算
   - 提示用户选择更长时间范围

4. **API限制**
   - 添加请求延迟（1秒间隔）
   - 避免频繁请求导致被封禁

```
MA5: 14.85元    MA20: 14.23元    MA60: 13.45元

布林带: 上轨16.12元 / 中轨14.85元 / 下轨13.58元

[趋势分析]

1. 价格突破MA20均线，短期趋势向上
2. RSI处于50-70区间，显示买方力量增强
3. MACD出现金叉信号
4. 价格运行在布林带中上轨，显示强势

[风险提示]
本分析仅供参考，不构成投资建议。

========================================
```
