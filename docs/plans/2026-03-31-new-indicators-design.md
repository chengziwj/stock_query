# 技术指标扩展设计文档

## 概述

为 stock_analyzer 项目添加10个新的技术分析指标，覆盖趋势、成交量、动量和市场情绪四大类别。

## 新增指标清单

| 指标 | 全称 | 类型 | 计算复杂度 |
|------|------|------|------------|
| SAR | 抛物线转向指标 | 趋势 | 中等 |
| ENV | 包络线 | 趋势 | 简单 |
| MFI | 资金流量指标 | 成交量 | 中等 |
| VROC | 成交量变动率 | 成交量 | 简单 |
| VWAP | 成交量加权平均价 | 成交量 | 简单 |
| ROC | 变动率指标 | 动量 | 简单 |
| MTM | 动量指标 | 动量 | 简单 |
| UOS | 终极指标 | 动量 | 复杂 |
| VR | 容量比率 | 情绪 | 中等 |
| ARBR | 人气意愿指标 | 情绪 | 中等 |

## 计算公式

### SAR（抛物线指标）

```
SAR(n+1) = SAR(n) + AF * (EP - SAR(n))
- AF：加速因子，从0.02开始，每次创新高/低加0.02，最大0.20
- EP：极值点（多头时为最高价，空头时为最低价）
- 转向条件：价格触及SAR时反转
```

### ENV（包络线）

```
上轨 = MA(N) * (1 + K%)
下轨 = MA(N) * (1 - K%)
- 默认：N=20, K=0.05（5%偏移）
```

### MFI（资金流量指标）

```
TP = (高+低+收) / 3
MF = TP * 成交量
PMF = 当TP上涨时的MF总和
NMF = 当TP下跌时的MF总和
MFI = 100 - 100 / (1 + PMF/NMF)
- 周期默认14
```

### VROC（成交量变动率）

```
VROC = (今日成交量 - N日前成交量) / N日前成交量 * 100
- 周期默认12
```

### VWAP（成交量加权平均价）

```
VWAP = Σ(典型价格 × 成交量) / Σ成交量
典型价格 = (高+低+收) / 3
```

### ROC（变动率指标）

```
ROC = (今日收盘 - N日前收盘) / N日前收盘 * 100
- 周期默认12
```

### MTM（动量指标）

```
MTM = 今日收盘 - N日前收盘
- 周期默认12
```

### UOS（终极指标）

```
TH = max(最高价, 昨日收盘)
TL = min(最低价, 昨日收盘)
ACC1 = Σ(TP-TL) / Σ(TH-TP) 周期7
ACC2 = Σ(TP-TL) / Σ(TH-TP) 周期14
ACC3 = Σ(TP-TL) / Σ(TH-TP) 周期28
UOS = 100 * (ACC1*4 + ACC2*2 + ACC3) / (4+2+1)
```

### VR（容量比率）

```
VR = (上涨日成交量总和 + 下跌日成交量/2) / (下跌日成交量总和 + 上涨日成交量/2) * 100
- 周期默认26
```

### ARBR（人气意愿指标）

```
AR = Σ(高-开) / Σ(开-低) * 100  (周期26)
BR = Σ(高-昨收) / Σ(昨收-低) * 100  (周期26)
```

## 信号解读

| 指标 | 买入信号 | 卖出信号 | 超买区 | 超卖区 |
|------|----------|----------|--------|--------|
| SAR | 价格上穿SAR | 价格下穿SAR | - | - |
| ENV | 价格触及下轨反弹 | 价格触及上轨回落 | 上轨附近 | 下轨附近 |
| MFI | MFI上穿20 | MFI下穿80 | >80 | <20 |
| VROC | VROC大幅上升 | VROC大幅下降 | - | - |
| VWAP | 价格>VWAP看多 | 价格<VWAP看空 | - | - |
| ROC | ROC上穿0 | ROC下穿0 | - | - |
| MTM | MTM上穿0 | MTM下穿0 | - | - |
| UOS | UOS上穿35 | UOS下穿70 | >70 | <35 |
| VR | VR>400强势 | VR<40弱势 | >450 | <40 |
| AR | AR>150活跃 | AR<50低迷 | >150 | <50 |
| BR | BR>300过热 | BR<50超卖 | >300 | <50 |
