**日期**: 2026-03-26
**版本**: 1.0
**方案**: 技术信号驱动（方案B）

## 1. 项目目标

构建一个基于技术分析的A股股票推荐系统，从全市场约5000只股票中筛选出综合评分最高的20只股票，并提供板块龙头看板功能。

## 2. 核心需求

| 需求项 | 规格 |
|--------|------|
| 推荐依据 | 综合技术指标、量价关系、趋势预测、风险控制 |
| 评分权重 | 技术40% + 量价30% + 趋势20% + 风控10% |
| 推荐范围 | 全市场A股（初步筛选后约3000-4000只） |
| 输出数量 | Top 20 |
| 触发方式 | 手动触发 |
| 附加功能 | 板块龙头看板 |

## 4. 模块设计

### 4.1 StockScreener（筛选器）

**职责**: 从全市场股票中初步筛选符合条件的股票

**筛选条件**:
- 剔除ST股票
- 剔除停牌股票
- 总市值 > 50亿人民币
- 近20日日均成交额 > 5000万

**接口**:
```python
class StockScreener:
    def get_all_stocks(self) -> List[str]:
        """获取全市场股票代码列表"""

    def apply_filters(self, stocks: List[str]) -> List[str]:
        """应用筛选条件"""

    def screen(self) -> List[str]:
        """执行完整筛选流程"""
```

### 4.2 StockScorer（评分器）

**职责**: 对单只股票进行综合评分

**评分体系**:

| 维度 | 权重 | 满分 | 指标 |
|------|------|------|------|
| 技术指标 | 40% | 40分 | MA排列、MACD、KDJ、RSI |
| 量价关系 | 30% | 30分 | 量价形态、资金流向、极端成交量 |
| 趋势预测 | 20% | 20分 | 趋势判断、预测置信度 |
| 风险控制 | 10% | 10分 | 波动率、位置风险 |

**详细评分规则**:

#### 技术指标（40分）

| 指标 | 满分 | 评分规则 |
|------|------|----------|
| MA排列 | 10分 | 多头排列: 10分；MA5>MA20>MA60: 7分；MA5>MA20: 4分；其他: 0-3分 |
| MACD | 10分 | 零轴上金叉: 10分；零轴下金叉: 6分；多头排列: 4分；死叉: 0分 |
| KDJ | 10分 | K上穿D且在20-80: 10分；<20金叉: 8分；>80死叉: 0分 |
| RSI | 10分 | 40-60: 5分；>60: 7-10分；<40: 0-3分 |

#### 量价关系（30分）

| 指标 | 满分 | 评分规则 |
|------|------|----------|
| 量价形态 | 15分 | 价升量增: 15分；放量突破: 13分；缩量盘整: 5分；其他: 2-12分 |
| 资金流向 | 10分 | 大幅流入: 10分；小幅流入: 7分；平衡: 5分；流出: 0-3分 |
| 极端成交量 | 5分 | 地量见地价: 5分；正常: 3分；天量见天价: 0分 |

#### 趋势预测（20分）

| 指标 | 满分 | 评分规则 |
|------|------|----------|
| 趋势判断 | 10分 | 看涨: 10分；震荡: 5分；看跌: 0分 |
| 预测置信度 | 10分 | 高: 10分；中: 6分；低: 3分 |

#### 风险控制（10分）

| 指标 | 满分 | 评分规则 |
|------|------|----------|
| 波动率 | 5分 | ATR适中: 5分；过高: 2分；过低: 3分 |
| 位置风险 | 5分 | 价格居中: 5分；接近阻力: 2分；接近支撑: 4分 |

**接口**:
```python
@dataclass
class ScoreBreakdown:
    technical: float      # 技术得分
    volume_price: float   # 量价得分
    trend: float          # 趋势得分
    risk: float           # 风控得分
    total: float          # 总分

class StockScorer:
    def __init__(self, weights: Dict[str, float] = None):
        """初始化评分器，可自定义权重"""

    def score(self, symbol: str) -> ScoreBreakdown:
        """对单只股票评分"""

    def score_batch(self, symbols: List[str]) -> List[Tuple[str, ScoreBreakdown]]:
        """批量评分（并发）"""
```

### 4.3 StockRecommender（推荐器）

**职责**: 整合筛选、分析、评分，生成最终推荐列表

**工作流程**:
```
1. 获取全市场股票列表
2. 应用初步筛选条件
3. 对剩余股票进行技术分析
4. 计算综合评分
5. 按评分排序取Top N
6. 格式化输出结果
```

**接口**:
```python
class StockRecommender:
    def __init__(self, top_n: int = 20, max_workers: int = 4):
        """
        初始化推荐器

        Args:
            top_n: 推荐数量
            max_workers: 并发工作线程数
        """

    def recommend(self) -> RecommendationResult:
        """
        执行推荐流程

        Returns:
            包含Top N股票详细信息的推荐结果
        """

    def recommend_by_sector(self, sector: str) -> List[StockRecommendation]:
        """按板块推荐"""
```

## 5. 性能优化策略

### 5.1 并发处理
- 使用 `concurrent.futures.ThreadPoolExecutor` 进行并发分析
- 默认4个worker，可配置
- 每只股票分析约需1-2秒，500只股票约需2-3分钟

### 5.2 缓存机制
- 当日已分析数据缓存到内存
- 避免重复获取相同股票数据

### 5.3 增量更新
- 只分析当日未分析的股票
- 支持中断后恢复
