# A股股票分析程序

专为A股设计的股票技术分析工具，集成多项技术指标、量价分析和价格预测功能。

## 功能特性

- **价格预测** - 基于趋势强度和量价关系的智能预测
- **量价分析** - 量价形态识别、资金流向分析、极端成交量检测
- **14项技术指标** - MA(5/10/20/60)、RSI、MACD、KDJ、DMI、布林带等
- **支撑阻力识别** - 自动识别关键价格位（前期高低点、黄金分割、成交量密集区）
- **智能买入建议** - 买入点位、止损价、目标价
- **特征工程** - 支持机器学习模型训练的特征提取
- **美化命令行界面** - 彩色输出、方框布局

## 快速开始

### 安装依赖

```bash
cd stock_analyzer
uv venv
uv pip install -r requirements.txt
```

### 运行分析

```bash
# 命令行模式
.venv\Scripts\python main.py 600519    # 按代码查询
.venv\Scripts\python main.py 比亚迪     # 按中文名称查询

# 交互模式
.venv\Scripts\python main.py
```

### 交互命令

| 命令 | 说明 |
|------|------|
| `help` | 查看所有指标解读 |
| `help:KDJ` | 查看单个指标说明 |
| `ref` | 查看指标快速参考卡 |
| `cls` | 清屏 |
| `q` | 退出程序 |

## 技术指标

| 类别 | 指标 | 说明 |
|------|------|------|
| 趋势 | MA(5/10/20/60)、MACD、布林带、BBI | 判断趋势方向 |
| 动量 | RSI、KDJ、WR、CCI | 超买超卖判断 |
| 强度 | DMI（+DI/-DI/ADX） | 趋势强度判断 |
| 成交量 | OBV、量比、MFI | 量能分析 |
| 波动率 | ATR、PSY | 波动性测量 |

## 量价形态

程序自动识别以下量价形态：

| 形态 | 含义 | 信号 |
|------|------|------|
| 价升量增 | 健康上涨 | 看涨 |
| 价升量缩 | 上涨乏力 | 看跌 |
| 价跌量增 | 恐慌抛售 | 看跌 |
| 价跌量缩 | 卖压减轻 | 看涨 |
| 放量突破 | 突破阻力 | 看涨 |
| 放量下跌 | 跌破支撑 | 看跌 |
| 缩量盘整 | 等待方向 | 中性 |
| 天量见天价 | 成交量极值+高位 | 看跌 |
| 地量见地价 | 成交量极值+低位 | 看涨 |

## 特征工程模块

支持机器学习模型训练的特征提取：

```python
from data_processor import DataProcessor

# 创建处理器
processor = DataProcessor(symbol='600519', months=12)

# 执行完整分析
result = processor.analyze()

# 获取特征
features = result['features']

# 准备训练数据
X, y = processor.prepare_training_data()
```

### 可用特征

| 类别 | 特征 |
|------|------|
| 收益率 | 1日/5日/20日收益率 |
| 波动率 | 历史波动率（年化） |
| 位置 | 价格位置（当前价/区间） |
| 趋势 | 均线排列得分、MACD信号、布林带位置 |
| 动量 | RSI、KDJ信号、OBV趋势 |
| 量价 | 量比、量价相关系数、量价形态 |
| 评分 | 超买/超卖评分、多空信号计数 |
