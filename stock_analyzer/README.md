# A股股票分析程序 (增强版)

专为A股设计的股票分析工具，集成技术指标、量价分析、价格预测功能。

## 功能特性

- 📈 **价格预测** - 基于趋势强度和量价关系的价格预测
- 📊 **量价分析** - 量价形态识别、资金流向分析
- 🎯 **12项技术指标** - 全面分析
- 🔍 **支撑阻力** - 智能识别关键价格位
- 💡 **买入建议** - 买入点位、止损、目标价
- 🎨 **美化界面** - 方框包裹、彩色输出

## 新增功能

### 价格预测
| 项目 | 说明 |
|------|------|
| 预测方向 | 上涨/下跌/震荡 |
| 预测概率 | 0-100% |
| 置信度 | 高/中/低 |
| 目标价格 | 短期/中期/长期 |
| 风险提示 | 预测失效条件 |

### 量价关系分析
| 形态 | 含义 | 信号 |
|------|------|------|
| 价升量增 | 健康上涨 | 看涨 |
| 价升量缩 | 上涨乏力 | 看跌 |
| 价跌量增 | 恐慌抛售 | 看跌 |
| 价跌量缩 | 卖压减轻 | 看涨 |
| 放量突破 | 突破确认 | 看涨 |
| 顶背离 | 价涨量缩 | 看跌 |
| 底背离 | 价跌量稳 | 看涨 |

### 资金流向
- MFI指标（资金流量指数）
- 资金净流入/流出百分比
- 资金流向状态判断

## 安装

```bash
cd stock_analyzer
uv venv
uv pip install -r requirements.txt
```

## 使用方法

### 命令行模式
```bash
.venv\Scripts\python main.py 600519    # 贵州茅台
.venv\Scripts\python main.py 比亚迪     # 中文名称
```

### 交互模式
```bash
.venv\Scripts\python main.py
```

### 内置命令
```
> 600519          # 分析股票
> help            # 查看所有指标列表
> help:KDJ        # 查看KDJ指标解读
> ref             # 显示快速参考卡
> cls             # 清屏
> q               # 退出
```
